# 內科順路共乘 — 簡報一頁大綱

目錄：[問題](#問題) · [解法](#解法) · [差異](#與-uber-的差異) · [Demo](#demo-流程) · [資料](#真實資料與模擬資料) · [100 天](#市府上任-100-天內要落地)

## 問題

- 目標：減少**同一時間**進內科的車流量；假設晨峰**一人一車**（待市府驗證）。
- 方法一：錯開上下班時段，留給我們的市長沈伯洋。
- 方法二：讓人共乘同一輛車（公車或共乘）。

## 解法

**順路共乘，平台即時媒合**：駕駛出發 → 乘客送出請求 → 駕駛確認 → 上車 → 結束。

## 與 Uber 的差異

Uber 讓**更多車**同時開進內科，違背目標；我們只載本來就要進內科的車。**強制標籤**、**自動改配**。

## Demo 流程

照[劇本](demo-script.md)：駕駛出發 → 乘客在松山車站看供給 → 強制「女性友善」送出 → 第一位駕駛婉拒，改配 → 確認 → 上車 → 結束

## 真實資料與模擬資料

- **真實：** 公車站（data.taipei，2026-10-18 快照）、Google Routes／Places；內科範圍為自行描繪。
- **預先選定：** 捷運站附近 3 個易上車的固定上車點（松山車站、世貿、大巨蛋）；可在駕駛目的地或指定公車站下車。
- **模擬：** 帳號、車輛位置、推播、車牌、標籤。

## 市府上任 100 天內要落地

- **第一步：** 請市府驗證「一人一車」這個假設，通過再開發。
- **局處：** 交通局（試辦路線）、停管單位（臨停）、公路局（法規）。
- **資料：** 僅商業資料（Google Routes／Places）。**成本：** 待估。
