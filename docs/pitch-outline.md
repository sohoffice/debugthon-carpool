# 內科上班順起來: 內科順路共乘 - 簡報一頁大綱

## 問題

太多車在**同一時間**進內科。

## 假設

晨峰大多**一人一車**（待市府驗證）。

## 解法

- 方法一：錯開上下班時段，留給我們的市長沈伯洋。
- 方法二：讓人共乘同一輛車（公車或共乘）。

## 我們的做法

**順路共乘，平台即時媒合：**

1. 駕駛出發
2. 乘客送出請求
3. 駕駛確認
4. 上車
5. 在駕駛目的地或沿途公車站下車
6. 結束

## 與 Uber 的差異

- Uber 讓**更多車**同時開進內科，違背目標；我們用本來就要進內科的車，載本來就要進內科的人。
- **強制與建議標籤**：強制標籤一定要符合；建議標籤只影響配對的優先順序。
- **自動改配**：駕駛婉拒時，平台改配下一台。
- **企業參與**：身分由企業認證（後續階段）。
- **同目的地優先**：終點越近（如同棟大樓）越優先。

## 真實資料與模擬資料

- **真實：** 公車站與路線（data.taipei）、車輛偵測器的位置（TDX）；路線、時間、地點搜尋與底圖用 Google（商業服務）。
- **自行定義：** 內科範圍、3 個上車點。
- **模擬：** 帳號、車牌、標籤、同企業、車輛位置、推播、天氣、共乘統計、車流（TDX 實測已取得，尚未接上畫面）、Demo 時間固定在 08:15；估計減少的車次與外部服務失敗時的路線是估算。
