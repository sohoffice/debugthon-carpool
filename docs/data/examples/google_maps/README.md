# Google Maps API examples

Each call has a pair of files: `<name>.request.json` and `<name>.response.json`.

- **Requests** are real. The API key is replaced with `<REDACTED>`.
- **Responses are fake.** They have the same shape as the real responses, but the values are made up (addresses, places, coordinates, times, IDs, and the polyline). Long lists are cut to one or a few items.

Google's terms do not allow storing or sharing Maps content, so real responses are not committed. Keep them in the git-ignored `tmp/google_maps/` folder.
