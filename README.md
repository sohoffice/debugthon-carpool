## Demo 流程

照[劇本](docs/demo-script.md)：駕駛出發 → 乘客在松山車站看供給 → 強制「女性友善」送出 → 第一位駕駛婉拒，改配 → 確認 → 上車 → 結束

## 真實資料與模擬資料

- **真實：** 公車站（data.taipei，2026-10-18 快照）、Google Routes／Places；內科範圍為自行描繪。
- **預先選定：** 捷運站附近 3 個易上車的固定上車點（松山車站、世貿、大巨蛋）；可在駕駛目的地或指定公車站下車。
- **模擬：** 帳號、車輛位置、推播、車牌、標籤。

## 市府上任 100 天內要落地

- **第一步：** 請市府驗證「一人一車」這個假設，通過再開發。
- **局處：** 交通局（試辦路線）、停管單位（臨停）、公路局（法規）、產業發展局（協助與企業溝通）。
- **企業：** 先邀 3 家內科企業試辦；由企業邀請員工、認證身分，誘因是員工福利、少用停車位、ESG。
- **資料：** 既有公車站開放資料，加上商業資料（Google Routes／Places）；不需市府另外提供。
- **成本：** 待估。
